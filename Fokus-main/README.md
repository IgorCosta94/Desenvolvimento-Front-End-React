# Fokus

Este projeto é uma experiência prática de produtividade, criada para ajudar a organizar o ritmo de estudo e trabalho. A interface combina um temporizador com modos de foco, descanso curto e descanso longo, além de uma lista de tarefas para acompanhar o que está em andamento.

## O que faz

- Alterna entre diferentes modos de concentração e descanso.
- Exibe um cronômetro visual para controlar a sessão.
- Permite adicionar, concluir e limpar tarefas.
- Oferece a opção de ligar ou desligar música enquanto a atividade acontece.

## Estilo do projeto

O resultado é uma interface leve, moderna e bem voltada para quem busca mais foco sem perder a organização.
