# Tecboard

Este projeto é uma pequena aplicação em React para organizar e exibir eventos de tecnologia com uma interface limpa e moderna. A proposta é reunir informações como título, data, imagem e tema em cards bem estruturados.

## O que o projeto oferece

- Criação de eventos com dados básicos e imagem.
- Organização dos itens por tema.
- Visualização em cards responsivos.
- Interface simples para experimentar componentes e estados em React.
