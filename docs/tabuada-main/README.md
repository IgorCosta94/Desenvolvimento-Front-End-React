# Tabuada

Este projeto é uma prática simples e direta de JavaScript, voltada para a geração dinâmica de uma tabuada. A ideia é mostrar como a lógica pode transformar uma página estática em algo interativo com pouco código.

## O que o projeto explora

- Estrutura básica em HTML.
- Manipulação do DOM com JavaScript.
- Geração automática de conteúdo a partir de dados informados.
