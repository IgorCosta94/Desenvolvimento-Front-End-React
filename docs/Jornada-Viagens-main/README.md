# Jornada Viagens

Esta pasta apresenta uma landing page dedicada a uma agência de viagens, com visual elegante e foco em despertar interesse pelo destino. O projeto mistura elementos de marketing, navegação e apresentação de ofertas de forma bem direta.

## Destaques

- Página inicial com mensagem forte sobre a experiência de viajar.
- Seção de ofertas da semana.
- Categorias de pacotes e destinos populares.
- Estrutura voltada para uma experiência visual agradável em dispositivos diferentes.
