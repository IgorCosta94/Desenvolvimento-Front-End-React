# TecBoard

Este projeto apresenta uma landing page voltada para monitoramento de aplicações, destacando a ideia de acompanhar sistemas em tempo real e atuar rapidamente quando algo sai do ar. A interface é objetiva, com foco em mensagem, branding e chamada para ação.

## Destaques

- Página inicial com proposta clara de monitoramento.
- Visual voltado para tecnologia e confiabilidade.
- Estrutura simples, mas com boa apresentação visual.
