# Pesquisa Culturama

Este projeto é um formulário completo, pensado para reunir informações do usuário de forma organizada. Ele aborda diferentes blocos, como dados pessoais, perfil, hábitos e opinião, dando uma boa noção de construção de formulários mais robustos.

## O que o projeto mostra

- Campos de texto, data, e-mail, telefone e foto.
- Seleções de gênero, estado civil e estado.
- Opções de preferências e hábitos pessoais.
- Uma página de confirmação ao final do envio.
