# Memoteca

Esta pasta reúne um projeto pensado para guardar ideias, frases e pensamentos de forma simples e visual. A proposta é criar uma pequena área de anotações com funcionalidades de criar, visualizar, editar e excluir entradas.

## O que você encontra

- Um formulário para adicionar novos pensamentos.
- Uma lista com os registros já salvos.
- A possibilidade de editar ou remover itens quando necessário.
- Uma simulação de backend com JSON Server para praticar operações CRUD.
