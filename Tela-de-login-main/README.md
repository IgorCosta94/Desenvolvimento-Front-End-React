# Tela de Login

Esta pasta reúne uma interface de autenticação estilizada, com foco em experiência visual e organização do formulário de acesso. O projeto é simples, mas consegue transmitir uma proposta clara e funcional.

## O que o projeto apresenta

- Cabeçalho com identidade visual.
- Formulário de login com usuário e senha.
- Layout limpo, com destaque para a área principal.
- Estrutura básica para estudar interação e estilização de telas de acesso.
